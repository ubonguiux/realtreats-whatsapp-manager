# Build status

Initial dashboard scaffold committed on 21 November 2026.

- React + Vite application
- Supabase email/password authentication scaffold
- Workspace-aware inbox UI
- Contact and account views
- Approval-first reply draft workflow (drafts only; no send operation wired)
- Supabase browser client configured through Vercel environment variables

WhatsApp transport, verified webhook processing, AI generation, and outbound sending are intentionally not enabled yet. Those require a server-side integration and explicit provider/account configuration.
